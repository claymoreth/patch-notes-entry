A one-line patch note for a real-life body bug: the brain waking the
body at 3am to replay an embarrassing moment from 2011 — fixed in
v3.2.0.

```
v3.2.0: fixed a bug where the brain woke the body at 3am to replay an embarrassing moment from 2011.
```

Run `python3 main.py` — it writes the line above to
`entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`), with no
trailing newline.
